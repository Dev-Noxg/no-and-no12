# no and no — WhatsApp Bot

بوت واتساب عربي، مع أوامر للمجموعات والأدوات والذكاء الاصطناعي.

## التشغيل في Replit

1. شغّل سير العمل **WhatsApp Bot** من لوحة Replit.
2. استخدم كود الربط الظاهر في سجل التشغيل لإضافة الجهاز من واتساب: **الأجهزة المرتبطة → ربط جهاز → الربط برقم الهاتف**.
3. بعد أول ربط، تُحفظ جلسة واتساب في `session/` ولا تحتاج لإعادة الربط عادةً.

لتشغيله يدويًا من جذر المشروع:

```sh
pnpm install
pnpm --filter @workspace/whatsapp-bot run dev
```

## تشغيل النسخة المضغوطة على Windows

1. فك ضغط الملف وافتح مجلد البوت.
2. شغّل `1-install.bat` لتثبيت المتطلبات.
3. انسخ `.env.example` إلى ملف جديد اسمه `.env`، ثم أضف مفتاح Groq الجديد إلى `GROQ_API_KEY`.
4. شغّل `2-start.bat`.

مفتاح Replit Secret لا ينتقل مع ZIP؛ ضعه محليًا في `.env`. الملف نفسه غير مرفق ومستثنى من Git. لا ترسل محتواه لأحد.

## مفاتيح الإعداد

- مفتاح الذكاء الاصطناعي محفوظ في Replit Secrets باسم `GROQ_API_KEY`.
- النموذج الافتراضي `openai/gpt-oss-20b`، ويمكن تغييره عبر `GROQ_MODEL`.
- لا تضع المفاتيح في `config.js` أو في المحادثات.
- أرقام البوت والمطورين مضبوطة في `config.js`.

## الأوامر المضافة

- **الروحانيات:** `/قرآن [رقم السورة أو اسمها]`، `/أذكار صباح|مساء`، `/صلاة المدينة, البلد`، `/حكمة`، `/حكمة_اليوم`.
- **المجتمع:** `/تحدي`، `/مفتاح JavaScript|Python|TypeScript|HTML|SQL`، `/ملاحظة أضف <نص>`، `/ملاحظة قائمة`، `/ملاحظة حذف <رقم>`، `/قرعة اختيار١ | اختيار٢`.
- **تذكير خاص:** `/رسالة_للمستقبل 2h نص الرسالة` في محادثة خاصة مع البوت. لا تُرسل الرسالة إلى مجموعة.
- **معلومات:** `/ويكيبيديا <موضوع>`، `/حالة_السيرفر` أو `/stats`، `/جلب_لوج`، `/أخطاء`، `/فحص`.
- **إدارة المطور:** `/إعادة_تشغيل`، `/إيقاف`، `/صيانة تشغيل|إيقاف`، `/حظر_عام` و`/الغاء_حظر_عام`.

## إذاعات المجموعات

الإذاعة لا تصل إلا للمجموعات التي يفعّل أدمنها `/استقبال_الإذاعة تشغيل`. يمكن إيقافها بـ`/استقبال_الإذاعة إيقاف`. ثم يرسل المطور `/إذاعة تأكيد <نص الإعلان>`؛ الحد الأقصى 15 مجموعة وافقت مسبقًا في كل مرة.

## حدود أمان مقصودة

- لا يوجد أمر `/eval` أو `/تنفيذ`: لا ينفّذ البوت JavaScript يرسله مستخدم عبر واتساب.
- `/زرف` معطّل لأنه كان يطرد كل أعضاء المجموعة ويغيّر إعداداتها بشكل جماعي.
- `/رسالة_للمستقبل` يرسل التذكير لصاحبه فقط.
- أوامر المطور لا تعمل إلا للأرقام المسجلة كمالكين في `config.js`.

## بيانات محلية

تُحفظ قاعدة البيانات في `database/db.json`، وجلسة واتساب في `session/`. كلاهما مستثنى من Git. احفظ نسخة احتياطية من قاعدة البيانات قبل نقل المشروع أو حذف مجلد الجلسة.
